The NEUROSENSE website is designed to present our AI-based wearable monitoring and emergency alert system developed for autistic children. It explains the purpose, features, working principle, sensor technology, and benefits of the device in a simple and user-friendly way. The website showcases how NEUROSENSE combines physiological, behavioral, environmental, and location data to identify unusual patterns and provide timely alerts to caregivers. It also highlights the project's vision of creating a safer, personalized, and technology-assisted environment for children while giving caregivers better access to meaningful information about the child's well-being.
